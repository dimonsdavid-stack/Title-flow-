# TitleFlow

Modern title & registration workflows for dealers and registration shops.

## Vercel Settings

Framework Preset: Next.js  
Install Command: npm install  
Build Command: npm run build  
Output Directory: leave blank  
Root Directory: leave blank if these files are at the repo root.

## Required repo root

Your GitHub repo root should contain:

- app/
- package.json
- next.config.js
- vercel.json

Do not put these inside another nested folder unless you set that nested folder as Vercel Root Directory.
